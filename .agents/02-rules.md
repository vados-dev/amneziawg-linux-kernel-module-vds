02 — Правила
Извлечено из файла AGENTS.md. Этот файл содержит правила работы агента.

1. Текущие планы в 03-plans.md работаем по нему.
2. Текущие задачи поставленные агенту задачи в 04-tasks.md.
3. Текущие проблемы агента в .agents/logs/$(date +'%Y%m%d%H%M')-issues.md.
4. Текущие заметки агента в .agents/logs/$(date +'%Y%m%d%H%M')-notes.md.
5. Отчёты агента в .agents/logs/$(date +'%Y%m%d%H%M')-reports.md.
6. Не выполнять самостоятельно и не автоматизировать запуски workflows, прописать, но закомментировать.
7. Документация, README.md и INSTALL.md на двух языках русский и английский с возможностью переключения, по умолчанию русский.
   Имена файлов английской версии с оканчиваются _en.(расширение).

# 00 — index

Не читайте все файлы. По умолчанию для сессии: этот файл + `01-purpose.md` + `02-rules.md` + `04-tasks.md` + `05-plans.md`.
После выполнения `05-issues.md`.
`06-debug.md` можно проверять результаты тестов.

| Файл | Когда |
|---|---|
| `01-purpose.md` | Всегда в начале. Что такое этот форк. |
| `02-rules.md` | Всегда в начале. Священные законы. |
| `03-tasks.md` | Текущие задачи поставленные владельцем. |
| `04-plans.md` | Планирование способов и порядка выполнения задач. Корректировка архитектором. |
| `05-issues.md` | Проблемы выявленные агентами. Ведёт архитектор. Ничего не удалят, пишет снизу вверх указывая в заголовках дату и время. |
| `06-debug.md` | Проблемы выявленные при отладке и тестировании владельцем. Результаты отладки владельцем. |

`AGENTS.md` — это только указатель. Обновите соответствующий файл `.agents/`, а не `AGENTS.md`.

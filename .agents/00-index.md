# 00 — index

Не читайте все файлы. По умолчанию для сессии: этот файл + `01-purpose.md` + `02-rules.md` + `03-tasks.md` + `04-plans.md`.
После выполнения `05-issues.md`.
`06-debug.md` — результаты отладки владельцем.

| Файл | Когда |
|---|---|
| `01-purpose.md` | Всегда в начале. Что такое этот форк. |
| `02-rules.md` | Всегда в начале. Священные законы. |
| `03-tasks.md` | Текущие задачи, поставленные владельцем. |
| `04-plans.md` | Планирование способов и порядка выполнения задач. Ведёт архитектор. |
| `05-issues.md` | Проблемы, выявленные агентами. Ведёт архитектор. Ничего не удалять; писать снизу вверх, указывая в заголовках дату и время. |
| `06-debug.md` | Проблемы, выявленные при отладке и тестировании владельцем. Результаты отладки владельцем. |
| `.agents/logs/YYYYMMDDHHMMSS-notes.md` | Заметки агента по правилу 4 из `02-rules.md`. |
| `.agents/logs/YYYYMMDDHHMMSS-reports.md` | Отчёты агента по правилу 5 из `02-rules.md`. |
| `.agents/logs/debug/` | Материалы отладки: логи, дампы, разбор compat.h. |

`AGENTS.md` — это только указатель. Обновляйте соответствующий файл `.agents/`, а не `AGENTS.md`.

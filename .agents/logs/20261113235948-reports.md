### 2. `scripts/setup.sh`

`install_deps` теперь:

1. пробует `dnf install -y dkms gcc make git tar gzip which curl`;
2. при ошибке ставит `dnf-plugins-core` и `epel-release`, включает CRB
   (`dnf config-manager --set-enabled crb`), обновляет кэш и повторяет установку;
3. возвращает ошибку только после повтора.

Причина: `dkms` в EL10 поставляется только из EPEL; в чистом quay-образе репозиторий
не подключён, и job падал на первом же пакете.

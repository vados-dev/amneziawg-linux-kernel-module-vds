## 7. Известные ограничения

- `merge.yml` требует, чтобы предыдущий тег upstream (`v<internal/config/version>`)
  существовал в клоне; иначе сравнение корневых файлов пропускается с предупреждением.
- Если upstream-тег не имеет префикса `v`, версия берётся из `src/version.h` upstream.
- `check-upstream.yml` при `run_merge=true` передаёт `dry_run` из своего входа; по умолчанию
  это `true`, то есть автоматический запуск не пишет в `master`.
